Wardbound / Pale Gambler - Combat Depth Pass 3

Main fixes
- Corrected arm-forward convention: negative X pitch is treated as the forward combat thrust.
- Runtime pose guard now forces both arms/hands to the forward hemisphere while a hand is active.
- Arm/hand geo chain is physically anchored 0.9 model units toward the face/front (negative Z) to stop coat-plane clipping.
- Replaced static combat arm poses with forward windup -> thrust -> recoil keyframes.
- Added dedicated animations for Stacked Deck, Buried Ace, Mirror Debt, House Edge and Double Down.
- Fixed stale/ghost telegraphs after the final wave of Starfall, Chip Storm, Buried Ace, Mirror Debt, House Edge and Double Down.
- Gambler streamed boss theme bind now clears a temporary stopping latch when the same boss becomes valid again.
- Gambler cosmetic cinematic packet now fails soft to a NOOP instead of disconnecting the client on malformed cosmetic data.

New combat patterns
HOUSE EDGE
- Rotating annulus plus card-blade spokes.
- Later phases add more waves/spokes and rotate the House edge between strikes.

DOUBLE DOWN
- Two opposite safe circles; the rest of the table is collected.
- Safe pair rotates between waves; phase 3 adds a third rotation.
