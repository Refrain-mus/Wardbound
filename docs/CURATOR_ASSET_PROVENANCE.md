# Asset provenance

The VFX atlas was created for this project using a generative image workflow. It was copied into `src/main/resources/assets/wardbound/textures/vfx/ashen_curator/source_atlas.png` and sliced into its 4 x 4 runtime cells. No Gambler artwork was recolored. `tools/curator_assets.py` reproduces the slicing, code-authored box UV swatches, GeckoLib mesh/animations, item models and original synthesized sound bank.

The precise generation prompt was:

> Create a production game VFX sprite atlas for Minecraft dark fantasy boss ASHEN CURATOR, archive horror, charred manuscript and ash. Exactly 1024x1024 square transparent background, regular 4x4 grid of 256x256 cells with substantial transparent padding within each cell. No words or labels. Each sprite isolated entirely inside its cell. Crisp detailed pixel art, ivory parchment, soot charcoal, oxidized copper ember orange, pale sage protection. Row1: hollow square torn manuscript frame (telegraph); filled scorched square manuscript (danger zone); square pale sage manuscript frame with small white corner brackets (safe archive); floating burned page with black illegible writing. Row2: thin hollow ash ring; fiery hollow ember ring; vertical column of fragmentary manuscript glyphs; open ivory book with burnt edges. Row3: ash sweep horizontal ribbon; burst of flying torn black text fragments; collapsing scorched archive wax seal; pale ivory victory plume shaped as rising pages. Row4: tall empty dark charcoal robe textile with ember cracks; long horizontal burned parchment catalog UI plate; rectangular copper archive seal icon; white ash mote. Orthographic flat sprite sheet, no perspective background, no grid lines, no decorative scene. Keep hollow area of rings transparent; maintain genuine alpha transparency.

The small white `boundary.png` is an exact geometry material. The boss skin uses deterministic, box-mapped soot/parchment/copper UV swatches, not a humanoid skin borrowed from the Gambler. The mesh and animations are authored in JSON and rendered with GeckoLib.

All sixteen sounds are synthetic placeholders generated from seeded noise, oscillators and envelopes, encoded to Ogg Vorbis with FFmpeg. No voice actor, third-party recording, professional composition or production audio mastering is claimed. `whispers.ogg` is nonverbal noise texture. `boss_theme.ogg` is a 48-second loop sketch. Replace these files with final audio using the same names; all events are already registered.
