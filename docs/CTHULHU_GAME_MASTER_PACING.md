# Wardbound — Master pacing and Cthulhu's Game depth pass

## Master pacing

Field-card Master pool/reveal thresholds now use:

- Ashen Curator: pool 16, identity reveal 36.
- Mourning Notary: pool 38, identity reveal 70.
- Pale Gambler: pool 68, identity reveal 108.
- Master signature hint/known defaults: 18 / 42 familiarity.

Before the first eligible Master enters the field-card pool, a sealed card is treated as an Unclaimed Hand. The mechanical fallback dealer is not allowed to gain audiences, relation, grudges, story progress, private signatures or dialogue. This closes the pre-pool Curator fallback leak.

Config schema 33 migrates exact historical signature defaults (5/12 or 12/28) to 18/42 while preserving deliberate custom values.

## Cthulhu's Game

- Constellation now uses all seven stars and retains the previous render-fix behavior.
- Mirror is a multi-verdict recognition exam (3 rounds, 4 on the weakness passage) with increasingly convincing near-miss reflections. A wrong answer rerolls the witness instead of allowing brute-force retries.
- Pressure is now an active regulation exam: continuous leakage, variable pump strokes, manual venting and 4-5 successive seal verdicts.
- Keyway no longer exposes a green shear window. It now hides the true gate behind a tension-response meter, adds false-set plateaus, and requires the player to distinguish a hollow give from the full gate peak across all four tumblers.
- Cipher remains coupled-ring logic; Yoke remains the multi-round coupled-axis/BIND exam from the coupled-axis revision.

The goal of these changes is to keep Cthulhu's Game from feeling like reduced one-click copies of the ordinary minigames.
