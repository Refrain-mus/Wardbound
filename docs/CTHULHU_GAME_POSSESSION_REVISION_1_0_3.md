# Cthulhu Game / Possession Revision

- Card Master pool entry and identity reveals are delayed substantially. Early field-card play no longer makes the three Masters feel immediately invested in the player.
- Generic master-signature familiarity defaults moved from 5/12 to 12/28.
- Cthulhu's Game Constellation keeps completed star links visible, has a larger field/hit treatment, visible hover rings, mistake feedback, and a short replay after failure.
- Cthulhu's Game Yoke is no longer an A-/A+ toy. It is a multi-round coupled two-axis valve puzzle with cross-axis disturbance and an explicit BIND verdict.
- Possessed wards now have gameplay states: input seizure, lurch/surge, Broken Metronome left-right reversal, and Hungry Pull delivered-input drag. Telegraphs explicitly state the temporary rule.
- Existing Eldritch refraction/time-splice/hush mechanics remain, now contrasted more clearly against Possession rather than both reading as generic shake.
