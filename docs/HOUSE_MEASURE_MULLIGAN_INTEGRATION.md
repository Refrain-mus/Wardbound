# House Measure + Cut integration

This pass deliberately does **not** add a separate card game or a separate family of late-game minigames.
It connects Wardbound's two existing loops.

## House Measure
After 90 resolved wards, eligible ordinary signed wards form a three-step cadence:
1. Opening
2. Pressure
3. Verdict

Verdict reuses one existing authored modifier: Reversed Face, Loaded Tempo, or Binding Clause. Special encounters (unsigned, Cthulhu, Eldritch/Gauntlet stages, possessed wards, chains and depth/reseal loops) do not consume the cadence.

Clean/Perfect execution across the three wards scores margin. A strong line banks one Cut; an exceptional line can bank two, with a hard reserve cap of two.

## Fold + Cut
Refusing an entire ordinary non-binding card hand is a tempo trade: the current hand is lost, but one Cut is banked if reserve space exists. Existing dealer relation/grudge/refusal consequences remain intact.

A Cut can later redraw exactly one visible offer in a normal hand. The server chooses the replacement, strongly preferring the removed card's family and preventing upward rarity fishing. Curse/Death forced hands cannot spend Cuts. The global card catalogue is never mutated.

The resource is one-shot and is consumed only after a valid replacement is produced.

## Cohesion goal
Minigame performance now earns card-selection agency, while card restraint creates future selection agency. The same existing minigame clauses become the third-round Verdict, so late-game difficulty asks the player to recombine learned Wardbound rules rather than learn an unrelated side game.
